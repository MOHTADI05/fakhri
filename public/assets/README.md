# Assets Bâtikub

Remplacez les placeholders SVG par vos fichiers définitifs :

| Fichier | Usage |
| --- | --- |
| `hero.glb` | Modèle 3D maison / briques (optionnel — sinon mur procédural) |
| `team.png` | Photo détourée de l'équipe |
| `artisan.png` | Photo verticale artisan / chef de chantier |
| `client-1.png` … | Portraits clients (avis) |
| `chantier-*.png` | Photos de chantier (timeline + réalisations) |
| `works-*.png` | Galerie réalisations |

Formats recommandés : WebP/PNG détourés pour les personnes, GLB compressé (Draco) pour le hero.
